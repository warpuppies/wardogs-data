# Data dictionary

Generated by `pnpm apply` from the schemas and the data. Do not edit. Game build 25937608.

## Conventions

- **Units.** Distances are meters, speeds meters per second, mass kilograms, angles degrees, time seconds. The game stores centimeters; the single conversion is divide by 100, applied when the data is built. Files with a `units` field say so; fields with a unit in their name (`massKg`, `diameterMm`, `max_speed_kmh`) keep it.
- **Ids.** Item and vehicle ids are the game's own tags (`Id.Item.AK74M`, `Vehicle.Variant.Air.Rotary.Havoc.Default`). The game compares tags without regard to case, and its own data is not consistent (`Id.Item.SKSBarrel` and `ID.Item.SKSBarrel` both occur), so compare ids case-insensitively. Every other file refers to items by these ids.
- **Coordinates.** One system per world: X and Y on the ground, Z up, in meters. A map image pixel is `(world - bounds.min) / metersPerPixel`, and image rows increase with world Y. Each world has its own `bounds`, and the terrain heightmap has its own bounds and `zRange`, so use each file's own values.
- **Versions.** Every file records the Steam `gameBuild` it came from and a `schemaVersion`. A game update shows up as a diff of these files.
- **Developer items.** The game ships a few items for development (test and debug). They stay in the data, flagged `developer: true` in `items.json`; join on that flag to leave them out of weapons, ammunition and other files that refer to items.
- **Absent fields.** An optional field that is not in a record means the game does not define it. It is never filled with a default.
- **Generated.** Everything under `data/` is written by `pnpm apply`; do not edit it by hand. `pnpm verify` checks every file against `MANIFEST.json`.

## Completeness

How much of the game each part of the data covers, and what is missing or uncertain.

| Area | Status | Files | Missing or uncertain |

| Weapons, ammunition, attachments | Complete | `weapons.json`<br>`ammo.json`<br>`attachments.json` | As stored in the game files. |
| Armor and equipment | Complete | `equipment.json` | - |

| Cosmetics | Complete | `cosmetics.json` | - |
| Loot | Partial | `loot.json` | Loot tables are complete. Spawn positions are created at runtime and are not in the game files. |

| Live server values | Not in the game files | - | Anything the server decides or overrides, the server list and player counts. The data is what the game files hold for one build. |

## Placed gameplay objects

Files: `data/maps/europe/objects.json`, `data/maps/kavkazi/objects.json`, `data/maps/north-america/objects.json`.

Gameplay objects placed in one world: shops, safe zones, spawn managers and volumes, vehicle deployment boards and fuel refills. Coordinates are the same as in map.json.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `schemaVersion` | 1 | yes | Version of this file's layout. It changes only when the layout does. |
| `world` | string | yes | Name of the world (level) the objects are in. |
| `gameBuild` | string | yes | Steam build id the data was extracted from. |
| `units` | "meters" | yes | Unit of every distance in the file. |
| `count` | integer | yes | Number of objects. |
| `objects` | list of object | yes | Objects, sorted by kind and then position. |
| `objects[].id` | string | yes | Stable id derived from the placed actor's name and the level it is in. |
| `objects[].kind` | "equipment-vendor" \| "vehicle-vendor" \| "garage-vendor" \| "safe-zone" \| "safe-zone-camera" \| "spawn-manager" \| "spawn-volume" \| "vehicle-deployment-board" \| "fuel-refill" | yes | What the object is: a shop (`equipment-vendor`, `vehicle-vendor`, `garage-vendor`), a team `safe-zone` with its `safe-zone-camera`, a team `spawn-manager`, a `spawn-volume` that vehicles appear in, a `vehicle-deployment-board` or a `fuel-refill` crate. |
| `objects[].class` | string | yes | Blueprint class of the actor. |
| `objects[].position` | [number, number, number] | yes | Position: [x, y, z] in meters. |
| `objects[].yaw` | number | no | Heading in degrees. Absent when the object is not rotated. |
| `objects[].scale` | [number, number, number] | no | Actor scale as stored. For a safe zone this sizes its trigger box. Absent when the game leaves it at 1. |
| `objects[].faction` | string | no | The team the object belongs to (`Alpha` or `Bravo`). Absent for neutral objects. |
| `objects[].tags` | list of string | no | Tags the object applies to people inside it (safe zones). |
| `objects[].allowedVehicles` | list of string | no | Vehicle ids a spawn volume may spawn (see items.json). |
| `objects[].disallowedVehicles` | list of string | no | Vehicle ids and vehicle families a spawn volume never spawns. |

## Buildings

Files: `data/maps/europe/buildings.json`, `data/maps/kavkazi/buildings.json`, `data/maps/north-america/buildings.json`.

Destructible buildings of one world as axis-aligned boxes. Z is up. Boxes enclose, so they overestimate.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `schemaVersion` | 1 | yes | Version of this file's layout. It changes only when the layout does. |
| `world` | string | yes | Name of the world (level) the buildings are in. |
| `gameBuild` | string | yes | Steam build id the data was extracted from. |
| `units` | "meters" | yes | Unit of every distance in the file. |
| `shape` | "axis-aligned bounding box" | yes | How each building is represented. |
| `count` | integer | yes | Number of buildings. |
| `buildings` | list of object | yes | Buildings, sorted by id. |
| `buildings[].id` | string | yes | Stable id derived from the placed actor's name. |
| `buildings[].kind` | "bungalow" \| "house" \| "apartment" \| "warehouse" \| "market" \| "shop" \| "garage" \| "office" \| "supply" \| "pool" | yes | Building category, derived from the blueprint class. |
| `buildings[].class` | string | yes | Blueprint class of the building. |
| `buildings[].min` | [number, number, number] | yes | Minimum corner of the box: [x, y, z] in meters. |
| `buildings[].max` | [number, number, number] | yes | Maximum corner of the box: [x, y, z] in meters. |
| `buildings[].parts` | integer | yes | Number of mesh parts whose bounds were merged into the box. |

## CSV tables

Flat copies of the data for spreadsheets. The first row is the header, cells are comma separated with RFC 4180 quoting, and empty means absent. Lists inside a cell are separated by `;`.

### `data/csv/achievements.csv`

One row per achievement.

| Column | Meaning |
| --- | --- |
| `id` | Achievement id. |
| `steam_id` | The achievement's id on Steam. |
| `name` | Name shown in the game. |
| `description` | What the achievement asks for, when the game words it. |
| `thresholds` | The numbers the game sets for the condition, as `name=value` separated by `;`. |

### `data/csv/ammo.csv`

One row per projectile definition (ballistics).

| Column | Meaning |
| --- | --- |
| `id` | Projectile id. |
| `asset` | Game asset path (several projectiles can share an id). |
| `damage` | Damage of one hit before falloff, armor and hit location. |
| `damage_type` | Damage type tag. |
| `mass_kg` | Projectile mass in kilograms. |
| `diameter_mm` | Diameter in millimeters. |
| `length_mm` | Length in millimeters. |
| `drag_coefficient` | Drag coefficient. |
| `drag_model` | Drag model, such as G7. |
| `typical_speed_mps` | Typical speed in meters per second. |
| `penetrates` | False when the projectile never passes through surfaces. |
| `exit_speed_multiplier` | Fraction of speed kept after passing through a surface. |
| `ricochet_min_angle_deg` | Impact angle above which it ricochets. |
| `explosive_radius_m` | Distance at which explosive damage reaches its minimum. |
| `explosive_effective_radius_m` | Distance within which explosive damage is full. |
| `suppression` | Suppression caused by a near miss. |
| `items` | Ammo items that fire it, separated by `;`. |
| `item_names` | Display names of those ammo items, separated by `;`. |

| `default` | Item the weapon starts with. |
| `default_name` | Display name of the default item. |
| `items` | Items accepted by name, separated by `;`. |

| `blocked_items` | Items refused by name, separated by `;`. |
